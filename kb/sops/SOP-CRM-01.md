# SOP-CRM-01 Salesforce reports or dashboards not refreshing

Applies to: Salesforce CRM
Symptoms: dashboard shows old data, report not updating, export report

Steps for the user:
1. Select Refresh on the dashboard; dashboards do not update automatically.
2. Check the report filters, especially the date range and 'My records' versus 'All records'.
3. To export a report, open it and select Export > Formatted report.
4. Clear the browser cache if the page shows layout errors.

Escalation: Escalate to CRM Support if data is missing for records that exist.
