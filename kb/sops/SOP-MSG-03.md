# SOP-MSG-03 Add a shared mailbox or shared calendar

Applies to: Microsoft Outlook / Exchange Online
Symptoms: how to open shared mailbox, add shared calendar, access team mailbox

Steps for the user:
1. Confirm that the owner of the shared mailbox has granted you access.
2. In Outlook, select File > Account Settings > Account Settings > Change > More Settings > Advanced > Add, and enter the mailbox name.
3. To add a shared calendar, open Calendar > Add calendar > From address book and select the calendar.
4. Restart Outlook if the mailbox does not appear within 30 minutes.

Escalation: Escalate to Messaging & Collaboration Support if access has been granted but the mailbox still does not open after one hour.
