# SOP-EUC-01 Laptop is slow or the disk is full

Applies to: Windows laptop / endpoint
Symptoms: laptop slow, computer freezing, disk full, low storage

Steps for the user:
1. Restart the laptop; do not only close the lid.
2. Install pending updates from Settings > Windows Update and restart again.
3. Run Disk Cleanup and delete temporary files; move large personal files to OneDrive.
4. Close applications that start automatically and are not needed (Task Manager > Startup).

Escalation: Escalate to End-User Computing if the laptop is still slow after updates or the disk fails.
