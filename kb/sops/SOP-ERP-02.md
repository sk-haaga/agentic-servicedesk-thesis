# SOP-ERP-02 SAP is slow or times out

Applies to: SAP S/4HANA Finance
Symptoms: sap slow, fiori loading forever, timeout, session expired

Steps for the user:
1. Close unused SAP sessions and browser tabs with Fiori apps.
2. Clear the browser cache and sign in to the Fiori launchpad again.
3. Try the same transaction in another browser.
4. Note the time, transaction and number of affected users.

Escalation: Escalate to ERP Finance Support if SAP is slow for several users or a critical finance process is blocked.
