# SOP-NET-01 VPN client shows 'Login failed'

Applies to: VPN / Remote Access
Symptoms: vpn login failed, authentication failed, cannot connect to vpn, credentials rejected

Steps for the user:
1. Check that Caps Lock is off and use your network password.
2. In the VPN client, select the connection profile 'Aurora-Staff' and try again.
3. If MFA prompts do not arrive, open the authenticator app and check that the phone time is set automatically.
4. Restart the laptop and reconnect.

Escalation: Escalate to Network & Remote Access if the error persists after step 4 or if several users report the same error (possible incident: raise impact).
