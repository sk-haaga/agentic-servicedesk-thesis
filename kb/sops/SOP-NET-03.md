# SOP-NET-03 Install and configure the VPN client on a new laptop

Applies to: VPN / Remote Access
Symptoms: how to install vpn, set up vpn on new laptop, vpn missing

Steps for the user:
1. Open the Company Portal app and install 'Aurora VPN Client'.
2. Start the client and enter the gateway address vpn.aurora-retail.example.
3. Select the profile 'Aurora-Staff' and sign in with your work account and MFA.
4. Enable 'Connect automatically' if you work remotely every day.

Escalation: Escalate to End-User Computing if the Company Portal does not list the VPN client.
