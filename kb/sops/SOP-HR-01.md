# SOP-HR-01 Workday: find payslips and record absences

Applies to: Workday HR portal
Symptoms: where is my payslip, how to request holiday, record sick leave, absence request

Steps for the user:
1. Sign in to Workday through the single sign-on portal.
2. Payslips: open the Pay application and select Payslips.
3. Absences: open the Absence application, select Request Absence, choose the dates and type and submit.
4. Check the status of a request in My Absence.

Escalation: Escalate to HR Applications Support if a payslip is missing or an absence balance is wrong.
