# SOP-MSG-02 Mailbox full or over quota

Applies to: Microsoft Outlook / Exchange Online
Symptoms: mailbox full, quota exceeded, cannot send because mailbox is full

Steps for the user:
1. Empty the Deleted Items and Junk Email folders.
2. Sort the mailbox by size and delete or save large attachments to OneDrive.
3. Turn on the Online Archive: File > Tools > Mailbox Cleanup > Archive older items.
4. Restart Outlook and check the mailbox size in File > Info.

Escalation: Escalate to Messaging & Collaboration Support if a mailbox quota increase is needed.
