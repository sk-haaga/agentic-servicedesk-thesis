# SOP-MSG-01 Outlook not sending or receiving email

Applies to: Microsoft Outlook / Exchange Online
Symptoms: emails stuck in outbox, no new emails, disconnected, working offline

Steps for the user:
1. Check the status bar: if it shows 'Working Offline', select Send/Receive > Work Offline to switch it off.
2. Close Outlook completely and start it again.
3. Open Outlook on the web (outlook.office.com). If email works there, the problem is in the desktop app.
4. Repair the Outlook profile: Control Panel > Mail > Show Profiles > Repair.
5. Clear the outbox: move stuck messages with large attachments to Drafts and resend them without the attachment.

Escalation: Escalate to Messaging & Collaboration Support if Outlook on the web also fails or several users are affected.
