# SOP-EUC-02 External monitor or docking station not working

Applies to: Windows laptop / endpoint
Symptoms: second screen not detected, docking station not working, monitor black

Steps for the user:
1. Disconnect and reconnect the docking station cable to the laptop.
2. Check that the monitor is switched on and set to the correct input.
3. Press Windows + P and select Extend.
4. Restart the laptop while it is connected to the docking station.

Escalation: Escalate to End-User Computing if the monitor or docking station appears faulty.
